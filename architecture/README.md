# Architecture Diagram

This folder contains the current architecture diagram for the Healthcare Staffing Metrics Pipeline.

## Files

- `healthcare_pipeline.png` is the exported architecture diagram used in the README and documentation.
- `source/healthcare_pipeline.drawio` is the editable diagrams.net / draw.io source file.

The public documentation references the PNG. The draw.io file is kept so the diagram can be edited later if the architecture changes.
