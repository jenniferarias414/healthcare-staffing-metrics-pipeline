# Local Project Assets

This project uses a local-only folder named `project-assets/` to organize original course materials and downloaded source files.

That folder is intentionally gitignored because it may contain:

- Original project instructions
- Course-provided PDFs or screenshots
- Downloaded source ZIP files
- Raw CSV files
- Data dictionaries
- Local reference notes

The public repository contains the reproducible project work:

- Source profiling scripts
- Architecture documentation
- Solution design
- Metric selection
- Transformation code
- Dashboard code
- Final summary and screenshots

Raw/source files should be downloaded or supplied separately and placed locally before running the pipeline.
